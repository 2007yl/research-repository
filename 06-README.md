#  Analysis Project

## Overview
This project analyzes Chronic pelvic pain among transgender and nonbinary individuals

## Methods
- Data cleaning in R
- Descriptive statistics
- Bivariate analysis

## Files
- `01-cleanup.R`: cleans and prepares the dataset
- `01-analysis.R`: runs statistical models
- `06-report.qmd`: report

## Notes
Original data are not included due to privacy/research restrictions.

## Publication
Chronic pelvic pain among transgender and nonbinary individuals: A retrospective analysis of a tertiary care chronic pelvic pain clinic
