#  Analysis Project

## Overview
This project analyzes surgical outcomes and racial disparity

## Methods
- Data cleaning in R
- Descriptive statistics
- Logistic regression models
  
## Files
- `01-cleanup.R`: clean and prepare the dataset
- `01-analysis.qmd`: analysis, discussion, report, response to reviewers

## Notes
Original data are not included due to privacy/research restrictions.

## Publication
Richardson, D., Lim, C. S., Liu, Y., et al. (2025). Identifying potentially modifiable risk factors 
associated with racially disparate postoperative outcomes following benign hysterectomy. 
American Journal of Obstetrics and Gynecology. 
https://doi.org/10.1016/j.ajog.2025.11.036
